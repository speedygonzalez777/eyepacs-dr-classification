# EyeQ quality labels

The `eyeq_quality` column of `metadata/manifest.csv` (Good / Usable / Reject) comes
from `Label_EyeQ_train.csv`: manual image quality grades for 12,543 images of the
Kaggle EyePACS **train** set. The file itself is kept on the
`users/rmichal/data-cleaning` branch.

- Source: https://github.com/HzFu/EyeQ, file `data/Label_EyeQ_train.csv`,
